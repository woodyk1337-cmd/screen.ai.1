# ScreenAI 1.0

Минимальный Android-проект: плавающее окно, ручной снимок экрана через MediaProjection и анализ изображения через выбранный API-провайдер.

## Провайдеры в первой версии

- Google Gemini — `gemini-2.5-flash`
- OpenAI — `gpt-4.1-mini`
- DeepSeek — `deepseek-flash`
- Groq — `qwen/qwen3.8-27b`

В приложении можно выбрать провайдера, сохранить его API key и открыть официальную страницу получения ключа в браузере.

## Сборка

1. Открой папку проекта в Android Studio.
2. Дождись синхронизации Gradle.
3. Подключи Android-телефон и нажми Run, либо выбери Build > Build APK(s).
4. Установи APK на устройство.

Требуется Android Studio с JDK 17 и Android SDK 35.

## Важные условия

- У каждого провайдера свои правила регистрации, лимиты и тарификация. Наличие страницы получения ключа не означает, что API бесплатный.
- ChatGPT-подписка не включает OpenAI API-баланс автоматически.
- Для несовершеннолетнего API-аккаунт, ключ и любые платёжные настройки должен оформлять и контролировать родитель/опекун.
- Не публикуй API-ключ. В этой демонстрационной версии ключ хранится в локальных SharedPreferences; это не защищённое хранилище для production.
- Скриншот отправляется выбранному провайдеру только после нажатия «Решить». Не используй функцию на экранах с паролями, личными сообщениями, платёжными и другими конфиденциальными данными.
- Android показывает системный индикатор/уведомление захвата экрана и может запрещать захват защищённого содержимого.
- Сборка и запуск на конкретном устройстве должны быть проверены в Android Studio; готовый APK в архив не включён.
